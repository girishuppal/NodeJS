# NVM Commands

---
`node --version` <br/>
Get node version

---
`nvm`<br/>
Displays node version manager number

---
`nvm install 26`<br/>
Install node js version 26

---
`nvm install --lts`<br/>
Install node version manager - long term support

---
`nvm use latest`<br/>
Use latest node version

---
`nvm ls`<br/>
List the current node version and available node version

---
`nvm install latest`<br/>
Downloads and install the latest node version
